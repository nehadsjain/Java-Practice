# Java Practice

Daily practice repository for strengthening Java fundamentals, DSA as part of my placement and internship preparation.

## 🎯 Purpose
This repo tracks my consistent, day-to-day learning — small programs, concept exercises, and 
problem-solving practice — rather than one big final project.

## 🛠️ Tech
- Java (JDK 21)
- IntelliJ IDEA

## 📈 Approach
Following a **broken → working → clean** method:
1. Write code that attempts the problem (even if imperfect)
2. Get it working correctly
3. Refactor for readability and best practices
